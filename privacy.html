Privacy policy

Last updated 10 November 2026

MegaManhwaRecap Uploader is an internal tool run by the operator of the MegaManhwaRecap YouTube channel. It uses the YouTube Data API and the YouTube Analytics API to upload videos, set their titles, descriptions, publish times and playlists, and read view statistics for videos on that one channel.

What it accesses

With the channel owner's consent through Google sign-in, the tool receives an OAuth token for the channel's Google account with the YouTube upload, YouTube management and YouTube Analytics read-only scopes.

What it stores

The OAuth token is stored on the operator's own computer and nowhere else. The tool keeps a local record of the videos it uploaded and their public statistics. It collects no information about viewers or any other person.

Sharing

Nothing is sold or shared with third parties. Data goes only between the operator's computer and Google's YouTube APIs.

Google API Services User Data Policy

The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be withdrawn at any time from the Google account's third-party access page, which invalidates the stored token.
